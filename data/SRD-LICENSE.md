# License of the game data in this folder

`srd-5.1/` and `srd-5.2/` contain material from the System Reference Documents only, converted to JSON and
edited (formatting, cross-references to content not included here turned into plain text) for NordvikManager.
They contain no artwork and no material from other books. Every file repeats its statement below in
`_meta.license`.
